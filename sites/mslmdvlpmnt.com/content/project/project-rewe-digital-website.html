REWE Digital Website

 Project Date: 15/10/2016

REWE Digital is responsible for the REWE Group’s online store. I started there as a front-end developer, after 1.5 years I took on the role of front-end architect in a platform based on microservices and another year later I was a UX engineer between design and development.

In addition to daily feature development, I introduced the ITCSS architecture, established automated UI testing with the Galen framework, built a Selenium test grid and set up a self-developed pattern library based on node.js.
