First paid website

 Project Date: 15/09/1999

I was working as a network administrator in a gynecological laboratory when the doctors there came to me and asked if I could also develop websites. And so I developed the first website for a client.

It had an intro page, a typical bad habit of sites of that time, a hand-drawn road map (Google Maps did not exist at that time) and actually every technique that you would be ashamed of today.

But this website marked the transition of my profession from a systems administrator to a web developer, from hobby to my current profession.
