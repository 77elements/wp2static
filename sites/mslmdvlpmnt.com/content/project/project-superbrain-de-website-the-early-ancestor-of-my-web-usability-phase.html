superbrain.de Website – The Early Ancestor of my Web Usability Phase

 Project Date: 05/04/1999

After the first swimming exercise, it was time to get into regular web publishing. At that time i was interested in the topics of increasing mental performance techniques, memorization optimization and brain-friendly learning and presentation methods. So this was the ideal domain name for it.

I had no idea back then that this would develop into Web Usability, Web Accessibility, Web Development and finally User Experience (UX) in the next few years.

superbrain.de was launched after a 14-day lasting nonstop day-and-night coding session. It had some Macromedia Flash components initially, which were then dropped relatively quickly, a guest book, which evolved into a forum later, a list of links to similar and related websites (there were barely a handful of them) and around 20 articles in 3 categories.

The brain you see in the screenshots was the entry page. Clicking on the different areas of the brain led directly to the corresponding section of the website. Intro pages were a thing back then, you know.
