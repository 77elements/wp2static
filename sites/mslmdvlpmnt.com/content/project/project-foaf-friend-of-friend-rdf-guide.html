FOAF – Friend of Friend RDF Guide

 Project Date: 18/07/2005

As I said, I was already very deeply involved in the semantic web topic and RDF formats when a new format emerged that could be used to represent human relationships in a decentralized way. With the emergence of centralized social media networks, this could have become an alternative basis for self-sufficient, self-regulated networks across the Internet.

I created an intro page about FOAF, similar to the What is RSS article.

But well, as already complained. Convenience won out, freedom and data sovereignty went down the drain. Nobody was interested in this article, or in the implementation of such a self-sufficient network.
