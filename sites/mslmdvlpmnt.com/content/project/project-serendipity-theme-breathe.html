Serendipity Theme: Breathe

 Project Date: 13/05/2007

I became more and more interested in the weblog system “Serendipity”, which originated in my home town and was programmed much more cleanly than WordPress, for example. It was also more stable and secure, as there were hardly any known security issues with these blogs. Only the ecosystem was a bit leaner. That’s why I wanted to help out with this theme (and a few others later). In the meantime, I had switched to Serendipity and used this theme on my blog.
