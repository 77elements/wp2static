fapulous framework Website

 Project Date: 12/12/2009

In 2008, Eric Sol published his “Faux Absolute Positioning” layout technique, which combines the best of float and absolute positioning techniques. I immediately liked the technique when I heard about it and was able to use it in a page builder project at imedo.

The fapulous framework is based on this technique. FAP is the abbreviation for ‘Faux Absolute Positioning’ and I simply combined it with ‘fabulous’.

This framework was still used long after I left some of my previous jobs. But some developer colleagues later asked me for a documentation, so I created this website.

I later used my own CSS framework in Istanbul too.
